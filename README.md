## Описание

**AI-модератор** — компонент для InstantCMS, который автоматически проверяет тексты комментариев и публикаций с помощью LLM (больших языковых моделей) и применяет настроенные действия: скрывает текст, отправляет на модерацию, удаляет или просто логирует.

Компонент работает в двух режимах:

- **Предмодерация** — проверяет текст до публикации. Подозрительный контент не появляется на сайте.
- **Постмодерация** — публикует контент сразу, а нарушения убирает после проверки в фоновом режиме.

Распознаваемые категории нарушений: **спам, реклама, оскорбления, мошенничество, разжигание ненависти, экстремизм, политический спам/пропаганда**.

## Как работают режимы

### Предмодерация

Проверка выполняется **до публикации**. Подозрительный контент не появляется на сайте.

**Комментарии**

Если ИИ вернул действие:

- `moderate` или `hide` — комментарий сохраняется с `is_approved = 0`, то есть **уходит на модерацию** и не публикуется сразу.
- `delete` — комментарий **полностью отклоняется** и не сохраняется.
- `log` или текст не спам — комментарий **пропускается**.

> Важно: настройка **«Что делать со спамом в комментариях»** (`comment_spam_action`) в предмодерации **не учитывается**. Она работает только в постмодерации, когда комментарий уже опубликован.

**Публикации (контент)**

- `moderate` — запись сохраняется с `is_approved = 0` и уходит на модерацию.
- `delete` — запись не публикуется (`is_approved = 0`, `is_pub = 0`).
- `log` / не спам — запись публикуется обычным порядком.

### Постмодерация

Контент публикуется **сразу**, а проверка выполняется в фоновом режиме после сохранения. Только после ответа LLM применяется выбранное в настройках действие (`comment_spam_action` / `content_spam_action`).

## Возможности

- Проверка **комментариев** и **публикаций** (статьи, посты и др.).
- Поддержка нескольких LLM-бэкендов:
  - **Ollama** — локальные модели, бесплатно и без интернета.
  - **YandexGPT** — облачная модель от Yandex Cloud.
  - **OpenAI / совместимые API** — OpenAI, OpenRouter и другие прокси.
- Настраиваемые действия при обнаружении нарушения:
  - отправка на модерацию,
  - удаление / отклонение,
  - замена текста на заглушку,
  - только запись в журнал.
- **Журнал проверок** с переходами к страницам нарушений.
- **Список нарушителей** с перепроверкой всех их записей.
- **Санкции** против авторов: понижение кармы, временный бан, личное предупреждение.
- **Чёрный список слов** и жёсткая блокировка по ссылкам.
- **Уведомления администраторов** в личных сообщениях.
- Проверка соединения с LLM прямо в настройках.
- Автоматическая проверка обновлений с GitHub.

## Системные требования

- InstantCMS **2.x**.
- PHP **8.0+**.
- Расширение PHP **curl** (для запросов к LLM).
- Расширение PHP **mbstring**.
- Для локальных моделей: установленный **Ollama** или доступ к нему по сети.
- Для облачных моделей: действующий API-ключ и баланс в Yandex Cloud / OpenAI / совместимом сервисе.

## Установка

1. Скачайте актуальный архив из [Releases](https://github.com/Kupers/ai_moderator-instantcms/releases).
2. Установите через панель администратора InstantCMS: **Компоненты → Установить пакет**.
3. Перейдите в **Компоненты → AI-модератор → Основное** и настройте бэкенд LLM.
4. Нажмите **Проверить соединение** и сохраните настройки.

## Поддерживаемые модели

- Ollama: `qwen2.5:7b`, `qwen2.5:3b`, `llama3.1:8b` и другие.
- YandexGPT: `yandexgpt/latest`, `yandexgpt-lite`, `yandexgpt-pro`.
- OpenAI: `gpt-4o-mini`, `gpt-4o` и др.

## Особенности моделей

> **YandexGPT**: хорошо справляется со спамом, рекламой, оскорблениями и мошенничеством, но при проверке текстов с ненавистью, экстремизмом или политической пропагандой может возвращать отказ вместо результата. Поэтому для категорий `hate`, `extremism` и `political` рекомендуется использовать локальные модели через **Ollama** (qwen/llama) — у них нет таких жёстких фильтров отказа.
